# Au-Care

Autism monitoring and intervention web app for the IIT Kanpur autism project (React + Firebase, no other backend).

The app is in [`webapp/`](webapp). See [webapp/README.md](webapp/README.md) for features, setup and the data model.

```bash
cd webapp
cp .env.example .env   # fill in your Firebase web config
npm install
npm run dev            # http://localhost:5180
```
